# Leeco-Serial 樂創串口调试终端

基于 PyQt6 开发的跨平台串口调试助手，深色主题界面，功能全面。

## 功能特性
- 串口热插拔自动检测，全参数配置（波特率/数据位/停止位/校验位）
- ASCII / HEX 双模式收发，支持毫秒级时间戳
- 定时发送、预设命令库、历史发送记录
- CRC16 校验自动追加、文件发送、日志保存
- DTR/RTS 电平控制，支持 ESP32 一键复位
- UTF-8 / GBK / ASCII 多编码切换
- 参数自动持久化记忆，启动自动恢复上次配置

## 运行环境
- Python 3.8 及以上
- 依赖库：PyQt6、pyserial
