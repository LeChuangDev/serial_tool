# 2026-11-01 工作日志

## 继续优化：原始字节缓冲改分块环形 + 降上限

- 新增 `serialtool/raw_buffer.py`：`ChunkedBytes` —— 分块字节环形缓冲（每块 64KB，丢弃整块出队 O(1)），
  取代 `main_window` 里单个 `bytearray` + `del buf[:n]`（O(n) memmove）的做法。导出走 `iter_chunks()` 流式，不再整体物化。
- `config.RX_RAW_CAP` 16MB → **8MB**；新增 `RX_RAW_CHUNK=64KiB`、`RX_RAW_CAP_DEFAULT_MB=8`。
- `main_window`：`_rx_raw` 改用 `ChunkedBytes`；`on_data_received` 仅当 `self._keep_raw` 时留存；
  `export_log_hex` 改为逐块流式写盘；`load_settings` 里按 `rx_raw_cap_mb`（默认 8，设 0 即不留存）重建缓冲，
  并读 `keep_raw`（默认 True，关掉可完全释放这部分内存）。
- 实测（offscreen + psutil）：环形缓冲峰值严格 ≤8MB，满容量下追加（丢一整块）0.009ms，流式导出 RSS 增量 +0.25MB（≈0）。
- 全量测试 `pytest tests -q` 仍全绿；ruff check / format 全过；新增 `tests/test_raw_buffer.py`。
- 接收区 @10000 行实测仅 +6MB（已 bounded），scope 存储 26MB 已最优，故本轮仅动原始字节缓冲这一项。
