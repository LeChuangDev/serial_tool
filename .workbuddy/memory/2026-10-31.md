# 2026-10-31

## 串口调试器 v3.4 第六轮（代码审视 → 修真缺陷 + 性能 + 架构拆分）

**起因**：用户问"还有什么优化的地方"。做了一轮完整审视，结论是"功能已经够多，真正的窟窿在
正确性、性能与文件规模"，按 P0→P1→P2 修完。

### P0 真缺陷（都已修）
1. **`btn_plot_pause` 从建好就没接过线** —— 面板有暂停按钮、`ScopeWidget.set_paused` 也有，
   但 `_bind_signals` 里漏了 connect，用户点了完全没反应。现在 `toggled → _on_plot_pause`
   （冻结曲线 + 按钮文字切"继续" + 图例显示"已暂停"）。教训：**建了控件必须查有没有接信号**，
   面板字段多时最容易漏。
2. **频谱/直方图/统计每帧全量重算**：`paintEvent` 30FPS 下每秒 30 次 1024 点纯 Python FFT +
   30 次 20 万点直方图遍历。实测直方图 **129ms/帧（391% CPU）**、频谱 11.4ms/帧。
   修法：`_revision` 数据版本号 + `self._cache` 结果缓存，`add_frame`/`set_channel_scale|offset`/
   `set_fft_points`/`set_window_seconds`/`import_meta`/`clear` 时 `_bump()` 作废。
   实测 → 直方图 1.9ms（**68x**）、频谱 1.6ms（**7x**）。
3. **CSV 导出读私有成员且导出原始值**：`_write_plot_csv` 直接访问 `scope._times/_series`，
   导出的是未标定值（与界面曲线对不上）。新增 `scope.export_rows()` 公开 API，走 `channel_values()`。

### P1 性能（绘制预算）
4. **`drawLines` 批量提交**代替逐列 `drawLine`（16 通道 × 上千列的主要开销）。
5. **等距抽样抽稀**：`decimate(..., step)`，点数 > 列数 × `SCOPE_DECIMATE_POINTS_PER_COL`(3) 时
   用 `islice` 抽样。抽样是子集 → 包络只会更窄，不会造出假尖峰。
6. **线段预算**：`SCOPE_MAX_LINE_SEGMENTS=12000`，超了把若干像素列合成一条粗线（col_div）。
   交替 A/B 实测 16 通道 @1200px：44 → 25ms（**-33%**），视觉几乎无损。
7. **自适应降帧**：`paintEvent` 计时 → `_adapt()` 平滑后按 `cost×1.5` 设 interval，
   夹在 `SCOPE_FPS(30)` 与 `SCOPE_MIN_FPS(10)` 之间，占空比 ≤ 2/3。
8. **空闲不重绘**：`_tick()` 在 `_revision == _painted_revision` 且无游标时直接 return
   —— 挂机/暂停时每秒 30 次全量重绘直接归零。
9. 每帧重复构造 `QFontMetrics`/`QColor` → 缓存 `_overlay_fm`/`_axis_fm`/`_color_cache`。
   注意：`_qcolor` 返回共享对象，**要改 alpha 必须先 `QColor(...)` 拷一份**（`_draw_histogram` 就这么做）。

**波形绘制成本模型**：≈ 通道数 × 像素列数 × 2µs。16 通道铺满 1200px ≈ 25~45ms/帧，
靠自适应降到 10~15FPS，UI 仍可操作。8 通道 × 1kHz 以内最流畅。

### P1 功能（对标 VOFA+）
10. **固定 Y 轴量程**：`set_y_range/set_auto_range/y_range` + `YRangeDialog`（自动/手动上下限）。
    `lo >= hi` 一律拒绝（否则 span<=0 → y_scale=inf → 绘制崩），paintEvent 里也做了兜底。
11. **通道元数据持久化**：`export_meta/import_meta`（JSON 落盘 `plot_channels`），
    非 list / 非法颜色 / NaN / 越界小数位全部收敛（`_is_color`/`_finite`）。
    同时改 `clear()` **保留 `_meta`** —— "清空"清的是曲线，不是用户调好的命名与标定。
    视图参数（时间窗/FFT/视图/Y量程）也一并落盘。settings_store 新增 `get_float`。

### 坑（勿回退）
- **`QFontDatabase.addApplicationFont` 必须在 `QApplication` 创建之后**，否则**直接段错误**（进程静默
  崩、连一行输出都没有，排查极费时间）。之前 v3.2 记忆只写了"加载 msyh.ttc"，没写顺序。
  正确顺序：`app = QApplication([])` → `addApplicationFont(...)` → 再构造窗口。
- **`QLineF` 在 `PyQt6.QtCore`，不在 `QtGui`**（ImportError 才会发现）。
- 本机 CPU 负载波动大，微基准单次测量能差 2 倍。**必须交替 A/B 多轮取最小值**，
  否则会得出"优化反而变慢"的错误结论（本次差点据此回退了有效的列合并）。
- Bash 工具默认 120s 超时会杀掉整套 pytest（现在 295 用例约 2m10s），要显式加大 timeout。
