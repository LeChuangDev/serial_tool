## 串口调试器 v2.3 企业级重构（serial_tool）

**环境**：Windows / Python 3.14.6 / PyQt6 6.11 / pyserial 3.5。用户实际运行 `py -3.14`，系统 `python` 指向 3.13 无依赖。
**验证方式**：`QT_QPA_PLATFORM=offscreen` 冒烟 + pytest（111 用例）+ 假 Serial 端到端，未接真实硬件。

### 结构（新增模块）
- `serialtool/panels.py`：声明式面板（SerialCard/DisplayCard/SignalCard/RecvPanel/SendPanel/MultiSendPanel），
  主窗口用 `_bind_panel()` 把控件挂成同名属性（Qt setupUi 惯例），布局代码与编排彻底分离。
- `serialtool/recv_pipeline.py`：`RecvFormatter` 增量解码/按行/HEX，脱离 Qt 可测。
- `serialtool/settings_store.py`：`SettingsStore` 收敛 QSettings 类型（注册表会读回字符串）。
- `serialtool/logging_setup.py`：RotatingFileHandler + sys/threading excepthook。
- `serialtool/widgets.py`：ClickComboBox/RecvPlainTextEdit/MiniRateChart/WaveChart。
- `tests/`：utils、recv_pipeline、settings_store、serial_worker、worker_loopback、main_window。

### 关键修复（有据可依，勿回退）
1. `SerialWorker.stop()`：对**未启动**的 QThread `isFinished()` 恒为 False → 空等满超时，已加提前返回。
2. `run()` finally 里清 `_stop` 会清掉新的停止请求 → 改在 `open()` 时清。
3. 写吞吐上限：原循环每轮最多写 4096B 后必等 50ms 读超时（≈80KB/s 天花板，逼近 921600 波特率）→ 预算改 64KB，有积压时用 2ms 让步让写优先。
4. 停止时聚合缓冲里的数据会丢 → finally 补发一批。
5. 读异常去重告警后不再重新武装 → 恢复正常时重置标志。
6. 端口下拉显示"COM3 · 描述"，真实设备名放 userData（`_current_port()`）。
7. 暂停时原始字节仍进 `_rx_raw`（HEX 导出完整性），只冻结渲染。

## 串口调试器 v3.0 第二轮（自动重连 + 界面重排）

**目标**：面向嵌入式调试，对标 SSCOM / XCOM / Tera Term / YAT / Termite 取舍功能。

### 新增模块（纯逻辑，可注入时钟/桩）
- `serialtool/ports.py`：`PortIdentity`（VID:PID + 序列号 + 描述）与 `match_score()` 打分
  （100 全同 / 85~90 仅端口名 / 80 序列号+VID:PID / 60 仅 VID:PID / 40 描述 / 0 无匹配），
  `pick_port()`、`PortScanner` 线程；`_natural_key()` 保证 COM9 < COM10。
- `serialtool/reconnect.py`：`ReconnectPolicy.delay_for()`（base*2^(n-1)，封顶 15s，±20% 抖动）、
  `ReconnectScheduler`（start/due/note_attempt/stop/exhausted/describe）。
- `serialtool/timestamps.py`：三模式 clock / elapsed / delta；`format_delta()` 输出 `12ms` / `1m02.500s`。
- `serialtool/highlight.py`：规则预编译、区间不重叠（先定义者优先）、JSON 序列化。
- `serialtool/rules_dialog.py`：`re:` 前缀表正则的文本编辑器，返回 `(rules, bad_lines)`。
- `serialtool/panels.py` 重写为 ConnectionBar/SessionCard/DisplayCard/StatsCard/RecvPanel/SendPanel。

### 链路
读失败持续 `LINK_LOSS_TIMEOUT`(2s) → `link_lost` 信号 → 重连调度 → 扫描 → 身份打分 → 重开。
`_user_close` 区分主动断开，避免点「断开」后自己连回来。

### 本轮修掉的坑（勿回退）
1. `TIMESTAMP_MODES` 是 label→mode 单向映射，`load_settings` 拿 store 里的 mode 当 label 查 → 永远落回 clock。
   补 `TS_MODE_LABELS` 反向表 + 5 个回归用例。
2. `test_plain_text_with_timestamp` 顺序依赖：前序用例把 cb_ts 改脏并经 QSettings 落盘。
   根因是配置在用例间共享 → conftest 加 `clean_settings` 夹具（每个用例前 `QSettings.clear()`）。
3. `_combo()` 用 `setFixedWidth` → 选中 `XON/XOFF` / `1500000` / `Space` 显示成 `XON/X…`。
   改 `setMinimumWidth(max(给定下限, sizeHint))`。
4. 窗口最小尺寸写死会随字体失效 → `_build_ui` 末尾用 `max(1120/680, minimumSizeHint())`，
   左侧窄栏最小宽 280→320。新增 `TestLayoutAudit` 用 sizeHint vs 实际尺寸做版式回归。
