## 串口调试器 v2.3 企业级重构（serial_tool）

**环境**：Windows / Python 3.14.6 / PyQt6 6.11 / pyserial 3.5。用户实际运行 `py -3.14`，系统 `python` 指向 3.13 无依赖。
**验证方式**：`QT_QPA_PLATFORM=offscreen` 冒烟 + pytest（111 用例）+ 假 Serial 端到端，未接真实硬件。

### 结构（新增模块）
- `serialtool/panels.py`：声明式面板（SerialCard/DisplayCard/SignalCard/RecvPanel/SendPanel/MultiSendPanel），
  主窗口用 `_bind_panel()` 把控件挂成同名属性（Qt setupUi 惯例），布局代码与编排彻底分离。
- `serialtool/recv_pipeline.py`：`RecvFormatter` 增量解码/按行/HEX，脱离 Qt 可测。
- `serialtool/settings_store.py`：`SettingsStore` 收敛 QSettings 类型（注册表会读回字符串）。
- `serialtool/logging_setup.py`：RotatingFileHandler + sys/threading excepthook。
- `serialtool/widgets.py`：ClickComboBox/RecvPlainTextEdit/MiniRateChart/WaveChart。
- `tests/`：utils、recv_pipeline、settings_store、serial_worker、worker_loopback、main_window。

### 关键修复（有据可依，勿回退）
1. `SerialWorker.stop()`：对**未启动**的 QThread `isFinished()` 恒为 False → 空等满超时，已加提前返回。
2. `run()` finally 里清 `_stop` 会清掉新的停止请求 → 改在 `open()` 时清。
3. 写吞吐上限：原循环每轮最多写 4096B 后必等 50ms 读超时（≈80KB/s 天花板，逼近 921600 波特率）→ 预算改 64KB，有积压时用 2ms 让步让写优先。
4. 停止时聚合缓冲里的数据会丢 → finally 补发一批。
5. 读异常去重告警后不再重新武装 → 恢复正常时重置标志。
6. 端口下拉显示"COM3 · 描述"，真实设备名放 userData（`_current_port()`）。
7. 暂停时原始字节仍进 `_rx_raw`（HEX 导出完整性），只冻结渲染。

### 企业级规范
- `pyproject.toml`：ruff（E/F/I/UP/B/C4/SIM/N/RET）+ pytest 配置；line-length 100。
- 未启用 PTH 规则：路径要与 PyInstaller `_MEIPASS` 同构，已写在配置注释里。
- `requirements.txt` / `requirements-dev.txt`。

### 遗留
- 连接/断开、文件发送未在真实硬件上回归（需 com0com 或真机回环）。
- `main_window.py` 仍 1473 行（纯编排），后续可再抽"日志会话""设置应用"两块。

## 串口调试器 v3.0 第二轮（自动重连 + 界面重排）

**目标**：面向嵌入式调试，对标 SSCOM / XCOM / Tera Term / YAT / Termite 取舍功能。

### 新增模块（纯逻辑，可注入时钟/桩）
- `serialtool/ports.py`：`PortIdentity`（VID:PID + 序列号 + 描述）与 `match_score()` 打分
  （100 全同 / 85~90 仅端口名 / 80 序列号+VID:PID / 60 仅 VID:PID / 40 描述 / 0 无匹配），
  `pick_port()`、`PortScanner` 线程；`_natural_key()` 保证 COM9 < COM10。
- `serialtool/reconnect.py`：`ReconnectPolicy.delay_for()`（base*2^(n-1)，封顶 15s，±20% 抖动）、
  `ReconnectScheduler`（start/due/note_attempt/stop/exhausted/describe）。
- `serialtool/timestamps.py`：三模式 clock / elapsed / delta；`format_delta()` 输出 `12ms` / `1m02.500s`。
- `serialtool/highlight.py`：规则预编译、区间不重叠（先定义者优先）、JSON 序列化。
- `serialtool/rules_dialog.py`：`re:` 前缀表正则的文本编辑器，返回 `(rules, bad_lines)`。
- `serialtool/panels.py` 重写为 ConnectionBar/SessionCard/DisplayCard/StatsCard/RecvPanel/SendPanel。

### 链路
读失败持续 `LINK_LOSS_TIMEOUT`(2s) → `link_lost` 信号 → 重连调度 → 扫描 → 身份打分 → 重开。
`_user_close` 区分主动断开，避免点「断开」后自己连回来。

### 本轮修掉的坑（勿回退）
1. `TIMESTAMP_MODES` 是 label→mode 单向映射，`load_settings` 拿 store 里的 mode 当 label 查 → 永远落回 clock。
   补 `TS_MODE_LABELS` 反向表 + 5 个回归用例。
2. `test_plain_text_with_timestamp` 顺序依赖：前序用例把 cb_ts 改脏并经 QSettings 落盘。
   根因是配置在用例间共享 → conftest 加 `clean_settings` 夹具（每个用例前 `QSettings.clear()`）。
3. `_combo()` 用 `setFixedWidth` → 选中 `XON/XOFF` / `1500000` / `Space` 显示成 `XON/X…`。
   改 `setMinimumWidth(max(给定下限, sizeHint))`。
4. 窗口最小尺寸写死会随字体失效 → `_build_ui` 末尾用 `max(1120/680, minimumSizeHint())`，
   左侧窄栏最小宽 280→320。新增 `TestLayoutAudit` 用 sizeHint vs 实际尺寸做版式回归。

### 验证
- `py -3.14 -m pytest tests -q` → **211 passed**；`ruff check` 全绿；`ruff format --check` 34 文件已格式化。
- 本机 offscreen 无字体（`QFontDatabase.families()` 返回 0），截图全是豆腐块 → 不产出 UI 截图，
  版式改用程序化审计（QWidget 几何 + sizeHint）代替肉眼看图。

### 遗留（README 第九章已写）
- 无序列号 CH340 双插同型号时可能认错板子；虚拟串口驱动拔出不一定抛异常（最慢要 5s 才发现）。
- 未在真实硬件跑 921600 长压测与 20 次插拔循环。

## 串口调试器 v3.1 第三轮（左上角双模式切换 + VOFA+ 风格协议绘图）

**目标**：仿 Trae 左上角模式切换；模式一保持原终端，模式二做 VOFA+ 式协议绘图，性能优于 VOFA+。

### 新增模块
- `serialtool/plot_protocol.py`：`JustFloatDecoder`（小端 float + 0x7F800000 帧尾，struct 批量解析）、
  `FireWaterDecoder`（CSV 文本）。纯逻辑。关键防呆：无帧尾/无换行的异常流有硬上限（4096 float / 64KB），
  不会像 VOFA+ 文档自述那样"缓冲爆满卡死"。
- `serialtool/scope.py`：`ScopeWidget` 多通道滚动示波器 + `decimate()` 纯函数（min/max 抽稀）。
  30FPS 节流重绘 + 环形缓冲限内存 + 自动量程 + 图例叠加。
- `panels.py`：新增 `ModeBar`（分段切换器，QButtonGroup 独占）、`PlotPanel`（协议/帧率/清空/暂停/示波器）。
- `config.py`：`MODE_*` / `PLOT_PROTOCOLS` / `SCOPE_*`（历史 20 万点、30FPS、16 通道上限、色板）。
- `styles.py`：`QFrame#segControl` 分段控件 QSS。
- `main_window.py`：`QStackedWidget` 承载两页（第0页 main_split / 第1页 plot_panel），
  `on_data_received` 按模式分流（绘图模式跳过文本渲染省 CPU），`switch_mode`/`_set_mode`/`_plot_feed` 等。

### 关键决策与坑（勿回退）
1. **协议分流**：绘图模式下 `on_data_received` 直接 return，不再跑文本/HEX/高亮管线——省 CPU。
2. **decimate 边界**：`int((t-t0)*scale)` 对负值向零截断会误入第 0 列，必须先用 `pos<0` 判断再 `int(pos)`。
3. **float32 量化**：`struct.pack('<f', 9.9)` 解回是 9.899999618530273，测试断言要用量化后的值，别直接 `== 9.9`。
4. **最小高度 680→760**：新增模式切换条占 ~44px 竖向，压扁左侧三卡片（statValue 标签 15→12px 被版式审计抓到）。
5. **状态栏 tip 过长**会挤压永久 `lab_status`（RX/TX 计数）→ 切换模式的 tip 改短为"已切换到绘图模式"。
6. 图片前导帧（双 inf）识别并丢弃，图片数据不渲染（README 已列限制）。

### 验证
- `pytest tests -q` → **236 passed**；`ruff check` 全绿；`ruff format` 39 文件。
- 双模式往返冒烟：绘图 500 帧/2 通道 → 切终端 hello 正常渲染，scope 曲线保留。

## 串口调试器 v3.2 第四轮（修布局重叠 + 绘图分析功能对标 VOFA+）

**目标**：修"按钮重合"、丰富功能做到比 VOFA+ 更好（学 vofa.plus/docs/learning）。

### 复现"按钮重合"的关键方法（务必沿用）
本机 offscreen `QFontDatabase.families()` 为 0，之前因此说"布局审计无裁剪"。但用户真机有
微软雅黑，文字更宽 → 左侧「显示」卡片 6 个复选框被垂直压到 6~7px、文字叠印。
**复现手法**：`QFontDatabase.addApplicationFont("C:/Windows/Fonts/msyh.ttc")` 后再跑
sizeHint vs 实际尺寸审计，即可在 offscreen 复现真机问题。这是本轮最重要的方法论。

### 根因与修复
1. **复选框被压缩重叠**：`setMinimumSize` 在 `_build_ui` 里（`load_settings` 之前）调用，
   此刻 `minimumSizeHint()` 被低估（761），而真机是 823；窗口 780 高不足 → 左侧卡片压缩。
   修复：`setMinimumSize` 抽成 `_apply_minimum_size()` 移到 `__init__` 末尾（load_settings 后）。
2. **QCheckBox 的 minimumSizeHint 不含文字**（Qt 行为），压缩时文字被裁。修复：`_checkbox()`
   辅助函数统一 `setMinimumHeight(20)` 兜底。
3. 精简左侧卡片：`make_card` spacing 9→6、statValue 15→13px、SessionCard/StatsCard grid 间距减小，
   把 minimumSizeHint 从 823 降到 782，默认窗口 780→800。

### 新增（对标 VOFA+ 的"直方统计 + 傅里叶变换"）
- `serialtool/analysis.py`：纯 Python 迭代 radix-2 FFT（无 numpy）、`fft_spectrum`（去直流+汉宁窗+
  补零）、`estimate_sample_rate`（时间戳估算采样率）、`histogram`、`channel_stats`(min/max/mean/rms/p2p)。
- `scope.py`：视图切换（wave/spectrum/histogram）+ 鼠标游标测量（`_nearest_index` 二分找最近点）+
  每通道统计。`_draw_grid` 拆出 X 轴标签（各视图自画，频谱画频率、直方图画数值）。
- `panels.py` PlotPanel：新增视图分段（波形/频谱/直方图）+ 通道下拉 + 时间窗 + FFT 点数 + 导出CSV + 统计标签。
- `main_window.py`：`_plot_feed` 末尾即时 `_sync_channel_combo()`；`_update_plot_stat` 每秒刷统计标签；
  `_write_plot_csv` 导出（时间戳+各通道，NaN 写空）。

### 验证
- `pytest tests -q` → **259 passed**（新增 analysis 14 + scope 5 + main_window 4）；
  `ruff check` 全绿；`ruff format` 41 文件。
- 绘图冒烟：1000 帧 2 通道 → CH1 min -1 max 1 rms 0.7071（正弦 RMS 正确）；FFT 50Hz 峰值定位正确。

### 坑（勿回退）
- FFT 测试断言用 `pytest.approx`，别 `==`；`_nearest_index` 等距点返回后者（0.005 到 0.0/0.01 等距 → 返回 1）。
- 绘图模式新帧后通道下拉靠 `_sync_channel_combo` 即时刷，统计标签靠 rate_timer 每秒刷（避免每帧算 stats 太贵）。
